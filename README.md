# 유니매치(UniMatch)
> 대학 입학전형 과목 추천 & 진로 매칭 플랫폼
## 소개
**UniMatch**는 고등학생들이 원하는 **대학교 / 학과 / 과목 선택 상황**에 따라:

- 필수과목과 선택과목을 쉽게 확인하고,
- 본인이 선택한 과목을 바탕으로 **지원 가능한 대학/학과**를 추천받을 수 있는 플랫폼입니다.

현재 각 대학교에서 제공하는 입학전형 예고사항은 정보가 방대하고 흩어져 있어 학생들이 찾기 어렵습니다. 또한 **고교학점제** 도입으로 인해 학생 개개인의 과목 선택 폭은 넓어졌지만, 그만큼 **어떤 과목이 진학에 유리한지 판단하기 어려운 문제**도 발생하고 있습니다.  

UniMatch는 이 문제를 해결해 학생, 학부모, 교사가 보다 직관적으로 정보를 확인할 수 있도록 돕습니다.
## 핵심 기능 (MVP)
- 대학별 과목 조회
    - 특정 대학교/학과 입력 시 → 필수/선택 과목 리스트 제공
- 역방향 추천
    - 학생이 듣는 과목 리스트 입력 시 → 지원 가능한 대학/학과 추천
- 비교 & 필터링
    - 대학별 전형요소(내신/수능 비중, 필수 과목 여부) 필터링
    - 여러 대학의 과목 요구사항을 한눈에 비교
## 기술 스택
- **Frontend**: React (Next.js / Vue.js 고려), TailwindCSS
- **Backend**: Node.js / Express 또는 Python (FastAPI)
- **Database**: PostgreSQL / MongoDB
- **AI/추천 엔진**:
    - 초기: Rule-based 필터링
    - 확장: Python (Pandas, Scikit-learn) 기반 추천 모델
    - 미래: LLM 기반 개인화 진로 추천
## 사용자 흐름 (MVP)
1. 학생이 원하는 학교/학과를 검색 → 필수/선택 과목 확인
2. 학생이 자신이 듣는 과목을 입력 → 지원 가능한 학교/학과 추천
3. 교사/학부모는 학생 상황 기반 자료 확인 → 진학 지도 활용
## 정기 목표
- AI 기반 개인 맞춤형 과목/학과 추천 (성적, 관심사, 선호도 반영)
- 커뮤니티 기능: 학생들이 과목 선택 및 진학 고민 공유
- 교사용/학부모용 대시보드 제공
- 해외 대학 입시 체계(IB/AP 등) 확장
## 차별화 포인트
- 단순 정보 제공을 넘어: **과목 선택 → 대학/학과 매칭 → 진로 설계**까지 연결되는 엔드-투-엔드 플랫폼
- 기존 입학자료 대비, **학생 맞춤형 접근**으로 직관적이고 효율적인 의사결정 지원
